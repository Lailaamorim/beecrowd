# 🐝 Beecrowd Challenges

![Beecrowd](/img/images-Photoroom.png)

> 📚 Resolvendo os desafios do beecrowd  
> 🚀 Evoluindo a lógica de programação com diferentes linguagens

Este repositório é dedicado à resolução dos desafios da plataforma **beecrowd**, utilizando diferentes linguagens de programação ao longo da jornada.

A primeira linguagem utilizada será **Python**, mas conforme o aprendizado evoluir, novos desafios serão resolvidos também em outras linguagens.

---

## 🎯 Objetivo

Concluir os desafios do **beecrowd**, explorando diferentes formas de resolver problemas e fortalecendo conhecimentos em:

- 🧠 Lógica de Programação
- 📊 Algoritmos
- 📦 Estruturas de Dados
- ⚡ Otimização de Código
- 💻 Boas práticas de desenvolvimento

Cada desafio será uma oportunidade de praticar, aprender e evoluir na programação.

---

## 🐝 Sobre o Beecrowd

O **beecrowd** é uma plataforma de programação competitiva e prática de algoritmos utilizada por estudantes e profissionais.

A plataforma possui diversos desafios com diferentes níveis de dificuldade, permitindo desenvolver habilidades como:

- Lógica de programação
- Resolução de problemas
- Estruturas de dados
- Algoritmos
- Raciocínio lógico
- Otimização de código

---

## 🚀 Linguagens Utilizadas

Os desafios serão resolvidos utilizando diferentes linguagens de programação.

### 🐍 Python

Será a primeira linguagem utilizada neste projeto.

Depois, conforme a evolução dos estudos, outras linguagens serão adicionadas:

- ☕ Java
- ⚙️ C
- 🔷 C++
- 🌐 JavaScript
- 🦀 Rust
- 🐹 Go
- 💎 Ruby

O objetivo é aprender diferentes maneiras de solucionar problemas utilizando linguagens distintas.
